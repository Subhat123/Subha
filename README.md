# TrendKart Fashion Retail Sales Analysis

## Project Overview

This project analyzes TrendKart fashion retail transaction data to understand sales performance, customer purchasing behavior, product trends, and revenue drivers. The dataset was cleaned, transformed, and analyzed using Microsoft Excel.

## Problem Statement

TrendKart wants to identify key sales trends, top-performing products and categories, customer purchasing patterns, and revenue drivers to support business decision-making.

## Dataset Information

* Dataset Name: TrendKart Fashion Enterprise Dataset
* Source: Project Dataset
* Records Included: Fashion retail transaction data
* Fields: Product details, customer details, sales amount, quantity, category, store details, payment method, sales channel, and transaction date.

## Tools and Excel Techniques Used

* Microsoft Excel
* Data Cleaning
* Remove Duplicates
* Sorting and Filtering
* Conditional Formatting
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards
* Dashboard Design

## Data Cleaning Process

The following data cleaning steps were performed:

1. Checked for missing values.
2. Identified duplicate records.
3. Corrected inconsistent formatting.
4. Standardized text values.
5. Verified data accuracy and consistency.
6. Preserved valid records without unnecessary deletion.

## Key Performance Indicators (KPIs)

* Total Sales
* Total Orders
* Total Quantity
* Total Profit
* Average Order Value
* Top Product Category
* Best Performing Product

## Dashboard Features

* Sales Overview

## Key Insights

* Certain product categories contributed the highest revenue.
* Top-performing products generated a significant share of overall sales.
* Customer purchasing patterns varied across different customer segments.
* Sales performance differed across stores and sales channels.
* Monthly sales showed variations across different periods.

## Recommendations

* Focus on high-performing product categories.
* Improve inventory planning for top-selling products.
* Promote underperforming products through targeted marketing campaigns.
* Develop targeted offers based on customer purchasing patterns.
* Monitor store and sales channel performance to identify growth opportunities.
