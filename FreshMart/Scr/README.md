# FreshMart Sales Transaction Analysis

## Project Overview
This project analyzes FreshMart sales transaction data to understand sales performance, customer purchasing behavior, and product trends. The dataset was cleaned, transformed, and visualized using Microsoft Excel.

## Problem Statement
FreshMart wants to identify key sales trends, top-performing products, customer purchasing patterns, and revenue drivers to support business decision-making.

## Dataset Information
- Dataset Name: FreshMart Sales Transactions
- Source: Project Dataset
- Records Included: Sales transaction data
- Fields: Product details, customer details, sales amount, quantity, category, payment method, and transaction date.

## Tools and Excel Techniques Used
- Microsoft Excel
- Data Cleaning
- Remove Duplicates
- Sorting and Filtering
- Conditional Formatting
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Dashboard Design

## Data Cleaning Process
The following data cleaning steps were performed:
1. Checked for missing values.
2. Removed duplicate records.
3. Corrected inconsistent formatting.
4. Standardized text values.
5. Verified data accuracy and consistency.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Average Order Value
- Top Product Category
- Best Performing Product
- Sales by Payment Method

## Dashboard Features
- Sales Overview
- Product Category Analysis
- Payment Method Analysis
- Monthly Sales Trend
- Interactive Slicers
- KPI Summary Cards

## Key Insights
- Certain product categories contributed the highest revenue.
- Digital payment methods were widely used.
- Monthly sales showed variations across periods.
- Top-selling products generated a significant share of revenue.

## Recommendations
- Focus on high-performing product categories.
- Improve inventory planning for top-selling products.
- Promote underperforming products through marketing campaigns.
- Encourage digital payment adoption through offers and discounts.
